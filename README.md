# ConectaClinica
ConectaClínica é uma API RESTful desenvolvida para integrar e otimizar a gestão de clínicas médicas. Ela centraliza o agendamento de consultas, a gestão de prontuários eletrônicos e o cadastro de pacientes e médicos em uma infraestrutura segura e ágil. Ideal para conectar aplicativos, portais de atendimento e sistemas de gestão em saúde.
